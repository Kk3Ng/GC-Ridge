# Third-party materials

The MIT license in `LICENSE` covers the project-owned implementation and documentation. Third-party assets retain their own terms; this repository does not grant a new license to dataset images, human annotations, CLIP or its pretrained weights.

| Source | Use and distribution in this version |
|---|---|
| [AGIQA-3K](https://github.com/lcysyzxdxc/AGIQA-3k-Database) | The official repository states that the database uses MIT. Its notice is retained in `third_party/AGIQA-3K-LICENSE`. We supply study split IDs and filename mappings; obtain MOS and images upstream. |
| [AIGCIQA2023](https://github.com/wangjiarui153/AIGCIQA2023) | Used as an existing benchmark. An explicit redistribution license was not found on the official repository page during the 2026-09-08 review. This version provides our split assignments and experimental outputs; it omits human MOS, prompt texts, images, features and trained heads. Users obtain the original quality annotations and images from the authors. |
| [OpenAI CLIP](https://github.com/openai/CLIP) | Optional dependency for local feature extraction. CLIP source and encoder checkpoints are not bundled; its source dependency is pinned in `requirements-features.txt`. |
| NumPy, SciPy, pandas and optional encoder dependencies | Installed from their respective distributions, not vendored. Their licenses remain applicable to those packages. |

The study does not introduce a newly collected image database. Please cite the original AGIQA-3K, AIGCIQA2023 and CLIP papers when using their work. No original dataset labels or images are licensed as our own outputs.

Local input and output directories are excluded by `.gitignore`. Do not upload local MOS, image features or checkpoints merely because they were generated by a command in this repository.
