# Version 1.0.0

- CPU GC-Ridge implementation, validation selection, component controls and prediction API.
- Fixed study splits, validation traces, model predictions, aggregate results and bootstrap draws.
- Official-annotation import with sample alignment and target fingerprints. Human MOS are joined locally and are absent from the repository.
- Optional official CLIP extraction with explicit image layouts, encoder checksums and feature fingerprints.
- Model fitting reports comparisons against archived predictions; strict archive checking is available explicitly.
- MIT license for the project-owned implementation, citation metadata and third-party notices.

The study and manuscript remain v23. This release changes how reproducibility inputs are obtained, without revising reported results or the research method.
